# tree-parser

A Python package for extracting structured content from PDF documents. It uses [Docling](https://github.com/docling-project/docling) under the hood for layout analysis and produces a hierarchical tree representation of the document.

## Features

- **TOC extraction** — Detects headings via Docling's standard pipeline and builds a table of contents. Supports both numbered headings (e.g. `1.2.3 Section`) and size-based level detection from bounding boxes.
- **Figure extraction** — Extracts all figures/pictures from the PDF, saved as PNGs organized by page number.
- **Single-pass processing** — `process_pdf()` runs Docling once to extract both TOC and figures, avoiding redundant PDF conversions.
- **Tree construction** — Parses a Markdown file against the TOC to build a tree of nodes (headings → content → children).
- **Markdown fallback** — If Docling does not detect headings and `toc.txt` is empty, the parser falls back to Markdown headings.
- **Output generation** — Produces `output_tree.json`, `output.txt`, `figures`, `toc.txt`.

## Output Structure

```
{output_dir}/{user}/{filename}/
├── toc.txt              # Table of contents (level;title per line)
├── {filename}.md        # Markdown (generated by caller, e.g. marker or VLM)
├── output_tree.json     # Hierarchical JSON tree
├── output.txt           # Flat text output
└── figures/
    ├── page_1/
    │   └── figure_1.png
    └── page_3/
        └── figure_2.png
```

## `output_tree.json` Format

```json
{
    "root": {
        "content": [],
        "children": [
            {
                "Section Heading": {
                    "content": [
                        {"type": "text", "content": "..."},
                        {"type": "table", "content": "..."}
                    ],
                    "children": []
                }
            }
        ]
    }
}
```

## API

### Module-level functions

| Function | Description |
|---|---|
| `extract_toc(pdf_path)` | Extract TOC from a PDF (single-purpose, runs Docling once). |
| `save_toc(toc, output_path)` | Write TOC entries to a file (`level;title` per line). |
| `extract_figures(pdf_path, output_dir)` | Extract all figures from a PDF as PNGs. |
| `process_pdf(pdf_path, output_dir, extract_images=True)` | Single Docling pass returning `(toc, figures)`. |

### `TreeParser` class

| Method | Description |
|---|---|
| `populate_tree(tree, toc=None, extract_images=False)` | Build the tree from a Markdown file + TOC. Pass a pre-computed `toc` to skip Docling. |
| `generate_output_json(tree)` | Write `output_tree.json`. |
| `generate_output_text(tree)` | Write `output.txt`. |
